How to Update

Halte deine Claude Code Knowledge Base aktuell — mit offiziellem Changelog und YouTube-Videos.

Keep your Claude Code Knowledge Base current — with the official Changelog and YouTube videos.

🔑
Trigger-Wörter

Der Updater wird nur aktiviert, wenn du eines dieser Schlüsselwörter in Antigravity sagst:

⚡ Aktivierungs-Befehle

update knowledge base update changelog KB updaten
⚠️ Wichtig: In allen anderen Situationen ignorieren sowohl Claude Code als auch Antigravity den Updater-Ordner (changelog-master) komplett. Er stört kein anderes Projekt!
1
Updater starten

Sage Antigravity eines der Trigger-Wörter. Es wird dann automatisch den Server starten:

# Claude Code startet das für dich, oder manuell:
cd .gemini/changelog-master
npm run dev:all

Antigravity sagt dir dann, dass du im Browser öffnen sollst:

http://localhost:5173
💡 Tipp: Beim ersten Mal musst du einmalig npm install ausführen und den Gemini API Key in die .env Datei eintragen.
2
Neue Inhalte einspeisen

Im Browser: Klicke auf den Tab „Knowledge Base" → „Ingest URL"

Du kannst zwei Arten von Quellen eingeben:

  • 📄 Changelog / Docs — z.B. den offiziellen Claude Code Changelog
  • 🎥 YouTube-Videos — z.B. Tutorials oder Ankündigungen

Die KI analysiert den Inhalt und schlägt passende Updates für deine Knowledge Base vor.

3
Updates prüfen

Jeder Vorschlag erscheint im Tab „Updates" mit dem Status:

● Pending — Wartet auf dein Review

Klicke auf 👁 (Auge) um den Diff zu sehen: Links das Original, rechts der Vorschlag.

Dann entscheidest du:

✓ Approve & Apply Übernimmt das Update sofort in die Knowledge Base

✕ Reject Lehnt den Vorschlag ab — nichts passiert

💡 Kein extra Schritt nötig! „Approve & Apply" schreibt die Datei direkt in deine lokale Knowledge Base. Kein CLI-Sync erforderlich.
4
In GitHub pushen (Snapshot Push)

Wenn du mit deinen Updates zufrieden bist, nutze den neuen Git Push Snapshot Button oben rechts neben den Tabs.

💡 Wie funktioniert der Login ohne .env?
Der Updater greift nativ auf deine lokale MacBook-Git-Konfiguration zurück! Da der changelog-master lokal in deinem Antigravity-Terminal als Child Process läuft, verwendet der `git push` Befehl im Hintergrund einfach deine bereits vorhandene Github Authentifizierung (z.B. den SSH Key oder gh auth). Keine extra Tokens nötig!
5
Fertig — Updater beenden

Wenn du fertig bist:

  1. Schließe den Browser-Tab
  2. Im Terminal: Ctrl+C drücken, um den Server zu stoppen

Dein Claude Code Teacher arbeitet jetzt mit dem neuesten Wissen! 🎉

⏱️
Neu: Auto-Heartbeat

Du musst Changelogs nicht mehr händisch suchen! Im Hintergrund (wenn der Server läuft) überprüft das System in regelmäßigen Abständen automatisch neue Changelogs. Findet es etwas, wird der Inhalt extrahiert und als fertiger Vorschlag im Updates-Tab für dich hinterlegt.

Sicherheit & Schutz
  • Duplikat-Schutz: Die gleiche URL kann nicht zweimal eingespeist werden
  • Human-in-the-Loop: Nichts wird ohne dein OK in die KB geschrieben
  • Rückgängig machen: Falls etwas nicht passt: git checkout -- .gemini/
  • Isolation: Der Updater stört keine anderen Projekte
🔑
Trigger Words

The updater is only activated when you say one of these keywords in Antigravity:

⚡ Activation Commands

update knowledge base update changelog KB updaten
⚠️ Important: In all other situations, both Claude Code and Antigravity completely ignore the updater folder (changelog-master). It won't interfere with any other project!
1
Start the Updater

Say one of the trigger words to Antigravity. It will automatically start the server:

# Claude Code does this for you, or manually:
cd .gemini/changelog-master
npm run dev:all

Antigravity will then tell you to open in your browser:

http://localhost:5173
💡 Tip: On first run, you need to execute npm install once and add your Gemini API Key to the .env file.
2
Ingest New Content

In the browser: Click the "Knowledge Base" tab → "Ingest URL"

You can enter two types of sources:

  • 📄 Changelog / Docs — e.g. the official Claude Code Changelog
  • 🎥 YouTube Videos — e.g. tutorials or announcements

The AI analyzes the content and suggests relevant updates for your Knowledge Base.

3
Review Updates

Each suggestion appears in the "Updates" tab with the status:

● Pending — Waiting for your review

Click 👁 (Eye) to see the diff: Original on the left, suggestion on the right.

Then you decide:

✓ Approve & Apply Applies the update immediately to your Knowledge Base

✕ Reject Rejects the suggestion — nothing happens

💡 No extra step needed! "Approve & Apply" writes the file directly to your local Knowledge Base. No CLI sync required.
4
Push to GitHub (Snapshot)

Once you're satisfied with your applied updates, click the new Git Push Snapshot button in the top right, next to the section tabs.

💡 How does it authenticate without an .env token?
The updater acts natively using your local Mac's Git configuration. Because the changelog-master runs locally inside your Antigravity terminal window as a child process, the `git push` command simply piggybacks on your existing Github authentication (like your SSH key or gh auth). No extra tokens needed!
5
Done — Stop the Updater

When you're finished:

  1. Close the browser tab
  2. In the terminal: Press Ctrl+C to stop the server

Your Claude Code Teacher now works with the latest knowledge! 🎉

⏱️
New: Auto-Heartbeat

No need to hunt for changelogs manually anymore! In the background (while the server is running), the system automatically polls for new official changelogs. If new entries are found, they are automatically generated directly into Updates tab proposals, waiting for your approval.
